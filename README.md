# RuPay Benefits

A private voucher and credit-card benefits management portal.

## Planned capabilities
- Manage cards and their benefit cycles
- Track vouchers by brand, source, expiry, and status
- Record bulk voucher purchases with supplier contact details
- Search brand-wise voucher inventory and view voucher provenance
- Prepare for a PostgreSQL database hosted on Oracle Cloud

## Status
Initial repository setup. Application implementation is next.
